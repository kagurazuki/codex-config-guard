# Sponsorship activation note

GitHub Sponsors is a candidate funding path for this OSS project, but no funding link is enabled in the repository package yet.

Activation should happen only after:

1. the maintainer's GitHub Sponsors profile/onboarding is complete;
2. the exact sponsor handle/link is verified;
3. the project has a real public repository and at least one validated public release.

At that point, add `.github/FUNDING.yml` with the verified GitHub Sponsors handle and add a short optional-support section to the README.

Do not ship placeholder funding handles or links.
